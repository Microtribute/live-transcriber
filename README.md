# Live Transcriber

A lightweight **Windows 11 utility that makes Windows Live Captions text selectable and copyable**.

Windows 11 Live Captions does a great job of transcribing system audio in real time, but the default Live Captions interface does not provide a convenient way to **select, copy, or reuse the generated transcription**.

Live Transcriber solves this problem by using Windows Live Captions as its transcription engine, while providing an interface where the generated text can be accessed and copied.

## How It Works

When Live Transcriber starts, it:

1. Launches **Windows 11 Live Captions** automatically.
2. Moves the Live Captions window outside the visible screen area to keep it out of the way.
3. Reads the transcription generated by Live Captions.
4. Displays the text through Live Transcriber, where it can be **selected, copied, and reused**.

```text
System Audio
     │
     ▼
Windows 11 Live Captions
     │
     │  Generated transcription
     ▼
Live Transcriber
     │
     ▼
Selectable / Copyable Text
```

## Why?

The built-in Windows Live Captions experience is primarily designed for **viewing** captions.

Live Transcriber adds the missing ability to **work with the transcription as text**.

This makes it useful for:

- Copying live transcriptions
- Saving transcripts
- Taking notes from videos or meetings
- Reusing caption text in other applications
- Processing live transcription in your own workflows

## Requirements

- **Windows 11**
- Windows Live Captions must be available on the system

> Windows 10, macOS, and Linux are not supported.

## Important

Live Transcriber **does not perform its own speech recognition**.

Windows Live Captions handles the speech-to-text conversion. Live Transcriber simply makes the resulting caption text accessible and usable.
